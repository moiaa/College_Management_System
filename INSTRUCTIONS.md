# Инструкция по установке, настройке и запуску

Документ содержит подробные системные требования, пошаговое руководство по развертыванию приложения **College Management System** с веб-интерфейсом в стиле **Material 3 Expressive**, а также описание ролевой модели и тестовых учетных записей.

---

## 💻 1. Системные требования

### 1.1. Программные требования
| Компонент | Минимальная версия | Рекомендуемая версия | Примечание |
|---|---|---|---|
| **Операционная система** | Windows 10 / Linux (Ubuntu 20.04+) / macOS 11+ | Windows 11 / Ubuntu 22.04 LTS / macOS 13+ | 64-битная архитектура (x86_64 или ARM64) |
| **Python** | 3.10 | 3.11 или 3.12 | Поддержка `asyncio`, type hints и FastAPI |
| **Менеджер пакетов** | `pip` 22.0+ | `pip` последней версии | Идет в комплекте с Python |
| **Веб-браузер** | Chrome 90+, Firefox 90+, Edge 90+, Safari 15+ | Любой актуальный Chromium-браузер | Поддержка CSS Variables, CSS Grid, Flexbox, ES6+ и cubic-bezier анимаций |

### 1.2. Аппаратные требования
- **Процессор:** 2 ядра с тактовой частотой от 1.6 ГГц.
- **Оперативная память (RAM):** минимум 512 МБ (рекомендуется 1 ГБ и более).
- **Свободное дисковое пространство:** не менее 250 МБ (с учетом виртуального окружения Python и локальной базы SQLite).
- **Сетевое подключение:** требуется для первоначальной загрузки зависимостей (pip); после этого приложение может работать полностью автономно (offline).

## 🚀 2. Пошаговая инструкция по запуску

### Шаг 1. Клонирование репозитория и переход в ветку
Если репозиторий ещё не склонирован:
```bash
git clone https://github.com/moiaa/College_Management_System.git
cd College_Management_System
git checkout feature/m3-design
```

### Шаг 2. Создание виртуального окружения (venv)
Рекомендуется использовать изолированное виртуальное окружение:

- **В Windows (PowerShell / Command Prompt):**
  ```powershell
  python -m venv venv
  ```
- **В Linux / macOS:**
  ```bash
  python3 -m venv venv
  ```

### Шаг 3. Активация виртуального окружения
- **Windows (PowerShell):**
  ```powershell
  .\venv\Scripts\Activate.ps1
  ```
  *(Если возникает ошибка выполнения сценариев PowerShell, выполните один раз: `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`)*

- **Windows (CMD):**
  ```cmd
  venv\Scripts\activate.bat
  ```

- **Linux / macOS:**
  ```bash
  source venv/bin/activate
  ```

### Шаг 4. Установка зависимостей
Установите все необходимые библиотеки:
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### Шаг 5. Инициализация базы данных
Создайте схему базы данных SQLite и наполните её демонстрационными пользователями:
```bash
python main.py init
```
*Команда создаст локальную базу `college.db` с готовыми тестовыми аккаунтами.*

### Шаг 6. Запуск веб-сервера
Запустите сервер приложения:
```bash
python main.py run
```
*Сервер запустится на адресе `http://127.0.0.1:8000/` с включенным режимом горячей перезагрузки (auto-reload).*

Для запуска на другом порту или хосте можно использовать параметры:
```bash
python main.py run --host 0.0.0.0 --port 8080
```

## 👥 4. Тестовые учетные записи и разграничение прав

Приложение содержит ролевую модель с автоматической адаптацией интерфейса:

| Роль | Логин | Пароль | Доступные разделы и возможности |
|---|---|---|---|
| **Студент** | `student` | `1234` | • **Электронный журнал**: персональный вид, колонка «Студент» заменена на «Предметы», отображаются только личные оценки, личный GPA, посещаемость и формы контроля.<br>• **Расписание**: расписание занятий группы.<br>• **Кабинет студента**: личные данные, зачётка, успеваемость. |
| **Преподаватель** | `teacher` | `1234` | • **Электронный журнал**: ведомость группы, выставление оценок (2, 3, 4, 5, Н, —), расчёт среднего балла группы.<br>• **Расписание**: личное расписание пар.<br>• **Учебные планы**: КТП и РПД.<br>• **Кабинет преподавателя**: нагрузка и журнал консультаций. |
| **Администратор** | `admin` | `admin` | • **Полный доступ** ко всем модулям системы.<br>• **Панель суперсил в журнале**: мгновенное переключение между «Ведомостью группы» и «Индивидуальным журналом любого студента».<br>• Выбор преподавателя и группы в личных кабинетах.<br>• **Админ-панель**: управление пользователями, группами и системными настройками. |

> **Смена учетной записи:** кликните по аватару/имени пользователя в верхнем правом углу (или в нижней панели на мобильных устройствах) и нажмите **«Выйти из аккаунта»**.

## ✨ 5. Особенности Material 3 Expressive

Интерфейс спроектирован по спецификации **Material 3 Expressive**:
1. **Пружинная физика (Damped Harmonic Oscillator):**
   - Пружинный овершут (`--spring-bouncy: cubic-bezier(0.34, 1.56, 0.64, 1)`).
   - Тактильный отклик (Squish Effect) при клике по кнопкам и оценкам (`scale(0.86)` / `scale(1.24)`).
   - Каскадное вылетание строк таблицы журнала с динамическим расчетом задержек.
   - Пружинные переходы между разделами и всплывающими диалогами.
2. **Адаптивность (Responsive Design):**
   - На экранах $\le 900px$ интерфейс трансформируется в мобильную нижнюю панель навигации (M3 Bottom Navigation Bar).
   - Аватар профиля интегрирован в нижнюю панель для быстрого доступа с мобильных устройств.
   - Горизонтальный скролл журнала с «липкой» (sticky) первой колонкой предметов/студентов.

## 🛠 6. Возможные проблемы и их решение

1. **Ошибка `Execution of scripts is disabled on this system` в PowerShell:**
   - Решение: выполните команду `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` и повторите активацию виртуального окружения.
2. **Ошибка `Address already in use` (порт 8000 занят):**
   - Решение: запустите сервер на другом порту: `python main.py run --port 8080`.
3. **Отсутствует файл базы данных `college.db`:**
   - Решение: выполните команду инициализации `python main.py init`.
