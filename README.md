## 📖 О проекте

Этот проект разрабатывается в рамках дисциплины "Разработка программных модулей" студентами 3 курса.

**Цель:** Создать современную модульную систему управления колледжем с интуитивным веб-интерфейсом, пружинными анимациями Material 3 Expressive и ролевой моделью (студент / преподаватель / администратор).

---

## 💻 Системные требования

- **Операционная система:** Windows 10/11, Linux (Ubuntu 20.04+), macOS 11+
- **Python:** 3.10, 3.11 или 3.12
- **Оперативная память:** от 512 МБ (рекомендуется 1 ГБ+)
- **Свободное место на диске:** от 250 МБ
- **Веб-браузер:** Google Chrome, Firefox, Safari, Edge, Яндекс.Браузер (актуальные версии с поддержкой CSS Variables, CSS Grid, Flexbox и ES6+)

## 🚀 Быстрый запуск

### 1. Клонирование и переход в ветку:
```bash
git clone https://github.com/moiaa/College_Management_System.git
cd College_Management_System
git checkout feature/m3-design
```

### 2. Создание и активация виртуального окружения:
- **Windows (PowerShell):**
  ```powershell
  python -m venv venv
  .\venv\Scripts\Activate.ps1
  ```
- **Linux / macOS:**
  ```bash
  python3 -m venv venv
  source venv/bin/activate
  ```

### 3. Установка зависимостей:
```bash
pip install -r requirements.txt
```

### 4. Инициализация базы данных:
```bash
python main.py init
```

### 5. Запуск веб-приложения:
```bash
python main.py run
```

Приложение будет доступно по адресу: **[http://127.0.0.1:8000/frontend/](http://127.0.0.1:8000/frontend/)**

## 🎨 Веб-интерфейс (Material 3 Expressive)

Ветка `feature/m3-design` включает полноценный веб-интерфейс, спроектированный по гайдлайнам **Google Material 3 Expressive**:
- **Пружинная кинетика (Spring Motion Physics):** упругие переходы между экранами, тактильный отклик кнопок (Squish Effect), каскадное появление строк таблицы журнала.
- **Персонализированный электронный журнал студента:** студент видит исключительно свои предметы, личные оценки, личный средний балл (GPA), процент посещаемости и формы итогового контроля (Экзамен/Зачет).
- **Ведомость преподавателя:** групповой журнал с оперативным выставлением оценок, фильтрацией и расчетом успеваемости.
- **Панель суперсил администратора:** возможность мгновенного переключения между сводной ведомостью группы и индивидуальным журналом любого учащегося.
- **Адаптивность (Responsive):** полная поддержка смартфонов и планшетов (M3 Bottom Navigation Bar, липкие колонки, тач-зоны).

## 🏗 Архитектура и модули

Проект имеет модульную архитектуру:
- **Core** (`core/`): аутентификация, модели БД, API-эндпоинты FastAPI, сессии.
- **Frontend** (`frontend/`): SPA на чистом стеке (HTML5, M3 Expressive CSS, ванильный JS), работающий автономно и быстро без тяжелых фреймворков.
- **Модули системы:**
  - *Gradebook* — электронный журнал (групповой и индивидуальный);
  - *Curriculum* — рабочие программы и КТП;
  - *Schedule* — расписание занятий;
  - *Reports* — аналитика и отчёты;
  - *Student Portal* — кабинет студента;
  - *Teacher Portal* — кабинет преподавателя;
  - *Admin Panel* — управление правами и структурой колледжа.
