## 📖 О проекте

Этот проект разрабатывается в рамках дисциплины "Разработка программных модулей" студентами 3 курса.

**Цель:** Создать модульную систему управления колледжем с использованием Python, Git и GitHub.

## 🏗 Архитектура

Проект имеет модульную архитектуру с ядром (`core/`) и независимыми
модулями. У каждого модуля — backend (`modules/<название>/`, Python/
FastAPI) и frontend (`frontend/<название>/`, обычный HTML/CSS/JS),
над которыми работают отдельные команды. Подробности — в
`docs/architecture.md`.

## 🚀 Установка

1. Клонируйте репозиторий
2. `python -m venv venv`
3. `source venv/bin/activate`
4. `pip install -r requirements.txt`
5. `python main.py init`

## 📦 Использование

```bash
python main.py run
```

Backend поднимется на `http://127.0.0.1:8000`, а фронтенд каждого
модуля — на `http://127.0.0.1:8000/frontend/<название>/` (рабочий
пример — `http://127.0.0.1:8000/frontend/_example/`).

## 🧩 Модули

- Gradebook — электронный журнал
- Curriculum — рабочие программы
- Schedule — расписание
- Reports — отчёты
- Student Portal — кабинет студента
- Teacher Portal — кабинет преподавателя
- Admin Panel — админ-панель
