# Пример фронтенд-страницы (образец, не один из 7 модулей)

Показывает минимальный рабочий паттерн: `fetch()` GET-списка,
`fetch()` POST создания новой записи, обработка ошибок, обновление
DOM без фреймворка. Ходит в тот же демонстрационный эндпоинт
`/api/v1/example/items`, что и `docs/examples/example_module/` на
бэкенде — значит, чтобы увидеть его в работе, backend-примеру не нужно
ничего дополнительно настраивать.

Откройте `http://127.0.0.1:8000/frontend/_example/` после
`python main.py init` и `python main.py run`.

Команда, разрабатывающая свой модуль, может скопировать `index.html`
себе в `frontend/<ваш_модуль>/` и заменить обращения к
`/api/v1/example/...` на эндпоинты своего backend-роутера.
